Federated Audience Composition Explained

Federated Audience Composition (FAC) is a feature in Adobe Experience Platform that allows you to build audiences directly from your enterprise data warehouse without copying the underlying data into Adobe Experience Platform.

Key Concept

Instead of replicating data, Federated Audience Composition enables you to:

  • Query data directly from your enterprise data warehouse (like Snowflake)
  • Build audiences using that federated data
  • Store only the resulting audiences in Adobe Experience Platform
  • Activate those audiences across channels while keeping raw data in your warehouse

How It Works

Federated Audience Composition provides a unique combination of:

1. Federated data approach - Access enterprise data without unnecessary duplication

2. Data curation - Build high-value audiences and attributes

3. Low-latency activation - Optimize for real-time cross-channel engagement

This results in less data movement while creating opportunities to utilize valuable audiences and attributes for consistent, low-latency activation across channels.

Key Differences from Standard Audience Composition

  • Standard Audience Composition has a 50 published composition limit per sandbox
  • Federated Audience Composition is not subject to that 50 composition guardrail — you can create more compositions
  • Federated compositions allow you to work with enterprise datasets without copying them to AEP

Typical Use Cases

  • Enriching existing AEP audiences with warehouse data
  • Building audiences from enterprise data directly
  • Creating personalized experiences using high-value attributes from your data warehouse
  • Reducing data duplication and integration complexity

Federated Audience Composition helps minimize unnecessary data copying while leveraging your existing tech stack to build and enrich audiences efficiently.
