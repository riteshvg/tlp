Deleting a Specific Old Batch from an AEP Dataset

Prerequisites

Before proceeding, note this critical limitation:

> ⚠️ You can only delete batches from datasets based on time-series schemas. Batches from record schema-based datasets cannot be deleted because record-type batches overwrite previous records and cannot be "undone". To fix erroneous record-schema data, you must re-ingest with correct data to overwrite it.

Option 1: Delete via the UI

1. In the Experience Platform UI, select Monitoring in the left navigation

2. Select either Batch end-to-end to view all batches

3. Locate your 2-month-old batch in the listing

4. Select the Batch ID to open the Batch overview dashboard

5. Select Delete batch near the top right of the dashboard

> ⚠️ Note: If the ingested data has been enabled for Profile and already processed, deleting the batch will NOT delete that data from the Profile store.

Option 2: Delete via API

Once you have your Batch ID and Dataset ID, make the following API call:

```http

POST /system/jobs

```

```shell

curl -X POST \

https://platform.adobe.io/data/core/ups/system/jobs \

-H 'Content-Type: application/json' \

-H 'Authorization: Bearer {ACCESS_TOKEN}' \

-H 'x-api-key: {API_KEY}' \

-H 'x-gw-ims-org-id: {ORG_ID}' \

-H 'x-sandbox-name: {SANDBOX_NAME}' \

-d '{

"datasetId": "YOUR_DATASET_ID",

"batchId": "YOUR_BATCH_ID"

}'

```

Finding Your Batch ID

If you don't know the exact Batch ID of your 2-month-old batch:

1. Go to Monitoring → Batch end-to-end in the AEP UI

2. Filter or scroll to find batches from ~2 months ago

3. Note the Batch ID from the listing — it will appear alongside ingestion start/end times, record counts, and dataset name
