How to Create a Data View in Customer Journey Analytics

Prerequisites

Before creating a data view, you must have an existing Connection set up in Customer Journey Analytics, as a data view is built on top of a connection.

Steps to Create a Data View

Step 1: Navigate to Data Views

1. Log in to Customer Journey Analytics at analytics.adobe.com

2. Select Data views from the top menu (optionally found under Data management)

Step 2: Initiate Creation

3. Select Create new data view

Step 3: Configure Tab

4. Select your existing Connection from the Connection list

5. Enter a Name for your data view

6. Optionally, add a Description

7. Select Save and continue

Step 4: Components Tab

8. Add schema fields and/or standard components to the METRICS or DIMENSIONS component boxes by dragging and dropping them

  • Most schema elements can be configured as either a dimension or a metric depending on your business requirements
  • Once you drag a schema element into the data view, options appear on the right where you can adjust how the dimension or metric operates
  • If working with ad hoc or relational fields, select Event datasets → Adhoc & Relational fields to access those specific fields

9. Optionally, create derived fields to modify field types, formats, or apply logic to existing fields

10. Select Save and continue

Step 5: Settings Tab

11. Review the settings (session, container, and calendar options)

12. Select Save and finish

Tips

  • Initial creation of a data view takes only a few minutes, but configuring each dimension and metric with the desired component settings can take several days
  • Settings tweaks apply retroactively, so your organization can refine them over time without losing historical data
  • You can always return to an existing data view and edit it by selecting it from the Data views list
