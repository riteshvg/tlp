Adobe Analytics Vs Adobe Customer Journey Analytics

Adobe Analytics vs. Customer Journey Analytics (CJA)

Fundamental Difference

The core difference between the two solutions is the breadth of data you can consider when building reports and analysis:

  • Adobe Analytics — Primarily aimed at online data collected from websites and mobile apps. It can import data from other sources, but mainly to provide additional context around online data.
  • Customer Journey Analytics — Any data source can be part of your reporting and analysis. It is built on Adobe Experience Platform and supports true cross-channel, person-level insights.

Key Comparison Areas

1. Data Collection & Architecture

| Feature | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Primary data source | Web & mobile (online) | Any data source (online + offline) |

| Data foundation | Report suites | Adobe Experience Platform datasets |

| Multi-channel data | Limited | Native (CRM, POS, mobile, web, etc.) |

| Data ingestion | AppMeasurement, Web SDK | AEP datasets, Analytics Source Connector |

2. Data Processing & Transformations

| Feature | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Processing rules | Processing rules, VISTA rules | Data Prep, Derived Fields |

| Report-time transformations | Limited (Virtual Report Suites) | Extensive (Data Views) |

| Historical data changes | Limited | Non-destructive, retroactive |

| Classifications | Classification sets | Lookup datasets |

3. Reporting & Analysis

| Feature | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Core interface | Analysis Workspace | Analysis Workspace |

| Segmentation | Segments (Visitor/Visit/Hit) | Filters (Person/Session/Event) |

| Virtual Report Suites | Yes | Replaced by Data Views |

| Cross-channel journeys | Limited | Native support |

| Stitching / Identity | ECID, AAID based | Graph-based & Field-based stitching |

4. Features Exclusive to Customer Journey Analytics

CJA offers several capabilities not available in Adobe Analytics:

  • 🔄 Report-time transformations via Data Views — alter or remove data without changing implementation
  • 📊 Derived Fields — combine, correct, or create data on the fly, applied retroactively
  • 🌐 Multi-channel reporting — collect and report on Web, POS, CRM, mobile, and more in one place
  • 🕐 Configurable sessions — define custom session timeouts and boundaries
  • 🔗 Cross-channel stitching — link anonymous and authenticated data across touchpoints
  • 🤖 Embedded Generative AI — predictive analytics and AI-powered insights
  • 🔒 Privacy-safe handling — built on AEP's privacy and governance framework
  • 📅 Transformations apply to historical AND new data — all changes are non-destructive

5. Identity & ID Management

| Identifier | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| AAID | Native | Via Analytics Source Connector |

| ECID | Native | Via Analytics Source Connector |

| Custom IDs | Limited | Fully supported |

| Identity stitching | Limited | Advanced (graph-based & field-based) |

6. Virtual Report Suites vs. Data Views

| Concept | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Equivalent feature | Virtual Report Suites | Data Views |

| Timezone configuration | Limited | Fully configurable & retroactive |

| Session timeout | Fixed | Fully configurable & retroactive |

| Metric/dimension control | Limited | Extensive |

| Sandboxing | N/A | AEP Sandbox support |

Summary: Which Should You Use?

| Use Case | Recommended Solution |

|---|---|

| Web & mobile analytics only | Adobe Analytics |

| Cross-channel customer journey analysis | Customer Journey Analytics |

| Offline + online data combination | Customer Journey Analytics |

| Advanced identity stitching | Customer Journey Analytics |

| Real-time web reporting | Adobe Analytics |

| AI-powered predictive analytics | Customer Journey Analytics |

| Integration with AEP ecosystem | Customer Journey Analytics |

Migration Considerations

If you are considering migrating from Adobe Analytics to CJA, key areas to evaluate include:

  • Data architecture changes — Moving from report suites to AEP datasets
  • Terminology differences — Segments → Filters, eVars/props → Dimensions, Report Suites → Data Views
  • Feature parity — Most Adobe Analytics features are supported in CJA, with some differences
  • Analytics Source Connector — Allows bringing existing Adobe Analytics data into CJA during transition
