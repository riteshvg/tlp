Using Out-of-the-Box AJO Datasets in CJA

Yes! You can use Adobe Journey Optimizer (AJO) out-of-the-box datasets in Customer Journey Analytics (CJA) and join them with other datasets.

How It Works

AJO automatically generates Journey Step Event datasets that can be ingested directly into CJA. The key to linking these with other datasets is the identity field.

Key Identity Field: `profileID`

  • The `profileID` field in the "Journey Step Event schema for Journey Orchestration" is defined as an Identity field
  • In CJA, this field acts as the person-based identifier
  • Any other dataset that shares the same value in its person identifier can be linked to the AJO Journey Step Event dataset

General Workflow

1. AJO generates the "Journey Step Event" dataset automatically (OOTB)

2. CJA ingests the Journey Step Event dataset via a Connection

3. Link datasets — using the `profileID` as the common identity, you can join the AJO dataset with any other dataset in CJA (e.g., web analytics, CRM, call center data)

4. Build a Connection in CJA that includes the AJO dataset alongside your other datasets

5. Create a Data View on top of that connection to expose the combined data for analysis

Use Case: Cross-Channel Journey Analysis

This setup is particularly powerful for cross-channel journey analysis — combining AJO journey data with other touchpoints to get a complete view of the customer experience across devices and channels.

Additional Tips

  • Use Data Prep if you need to resolve schema differences or field mapping conflicts between datasets
  • Enable Stitching in CJA if your datasets use different ID namespaces, to resolve them into a single unified customer ID
