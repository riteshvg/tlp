Top-Level Profile Attributes on the Edge in AEP

Yes, top-level profile attributes are available on the Edge Network in Adobe Experience Platform, though with some important context and constraints.

How Edge Profiles Work

Edge profiles are lightweight versions of the full Real-Time Customer Profile that are distributed across Edge Network locations geographically closer to end users. They are designed specifically for speed and real-time personalization, rather than the full comprehensiveness of the hub-based profile.

According to the documentation, the data that lives on the Edge Network includes:

  • Audience memberships
  • Profile identities
  • Attributes necessary for personalization

So profile attributes are available on the edge — but only those projected to the edge for personalization use cases, not the full set of historical and rich profile attributes stored at the hub.

Viewing Edge Attributes in the UI

You can verify which attributes are available on the edge directly in the AEP Profile UI:

1. Navigate to a specific profile in [!UICONTROL Real-Time Customer Profile]

2. Select the [!UICONTROL Attributes] tab

3. Use the data location selector and choose [!UICONTROL Edge]

This will display only the attributes currently available on the edge for that profile.

Key Requirements for Edge Attribute Availability

For profile attributes to be available and used correctly on the edge, you need to ensure:

1. Datastream configuration: When configuring your datastream in Data Collection UI, ensure [!UICONTROL Edge Segmentation] and [!UICONTROL Personalization Destinations] are enabled under Adobe Experience Platform settings.

2. Active-On-Edge Merge Policy: You must create and set an [!UICONTROL Active-On-Edge Merge Policy] as default. Edge destinations only support audiences that use this merge policy — without it, attributes and audiences will not be evaluated at the edge.

3. Personalization Destination connection: A destination such as Custom Personalization or Adobe Target must be configured to send profile attributes to the Edge Network.

Hub vs. Edge: Key Distinction

| Aspect | Hub | Edge Network |

|---|---|---|

| Data completeness | Full historical + rich profile data | Lightweight — only what's needed for personalization |

| Use case priority | Thoroughness | Speed / real-time |

| Attribute availability | All ingested profile attributes | Attributes projected/necessary for personalization |

| Segmentation | Batch + Streaming | Edge segmentation |

Summary

Top-level profile attributes are available on the edge, but only the subset that has been projected to the edge for real-time personalization. The full richness of the hub profile is not replicated to the edge. Proper configuration of your datastream, Active-On-Edge merge policy, and personalization destination are prerequisites for those attributes to be accessible at the edge.
