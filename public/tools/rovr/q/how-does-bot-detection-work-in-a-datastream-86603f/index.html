how does bot detection work in a datastream?

Bot Detection in Datastreams

Bot detection in Adobe Experience Platform datastreams helps you identify and filter out automated, non-human traffic — such as search engine crawlers, monitoring tools, and other bots — so they don't skew your analytics data.

How to Enable Bot Detection

Bot detection is configured at the datastream level. You must have an existing datastream before enabling it.

Prerequisites: A datastream must already be created and configured.

Steps:

1. Navigate to [!UICONTROL Datastreams] in the left navigation of the Adobe Experience Platform UI or Data Collection UI.

2. Select the datastream to which you want to add bot detection.

3. In the datastream details page, select [!UICONTROL Bot Detection] from the right rail.

4. The [!UICONTROL Bot Detection Rules] page is displayed.

Two Methods of Bot Detection

1. IAB/ABC International Spiders and Bots List

This is a third-party, industry-standard list of known internet spiders and bots maintained by the IAB/ABC. It covers automated traffic such as:

  • Search engine crawlers
  • Monitoring tools
  • Other non-human traffic

To enable it:

1. Toggle on [!UICONTROL Use IAB/ABC International Spiders and Bots List for bot detection on this datastream].

2. Select [!UICONTROL Save].

2. Custom Bot Detection Rules

You can also create your own bot detection rules tailored to your specific traffic patterns and use cases.

How Bot Detection Interacts with Other Datastream Features

Bot detection runs before Dynamic Datastream Configuration rule evaluation. When bot detection identifies a potential bot, it tags the event with a `botDetection.score` field. Dynamic Datastream Configurations can then reference this field as a condition in routing rules.

This makes the two features complementary:

  • Bot detection identifies bot traffic and scores it.
  • Dynamic Datastream Configurations act on that identification — routing or discarding the flagged events based on the score.

> Note: Allow up to 15 minutes for bot detection rules to propagate before testing your configuration. Also, if you're integrating with Dynamic Datastream Configurations, you'll need to add the Bot Detection Information field group to your XDM schema.
