Is an Event Dataset Mandatory When Setting Up a Datastream?

No, an event dataset is not strictly mandatory to create and save a datastream. However, it depends on which services you enable in the datastream.

When an Event Dataset IS Required

If you enable the Adobe Experience Platform service in your datastream, you must select an Event Dataset. This is because the AEP service needs to know which dataset to route your incoming event data to.

Steps when adding AEP as a service:

1. Create your datastream via Datastreams in the left navigation of the AEP or Data Collection UI.

2. Select Add Service and choose Adobe Experience Platform.

3. You are required to select an Event Dataset from the list before saving.

When an Event Dataset is NOT Required

If you are not enabling the Adobe Experience Platform service — for example, if your datastream only routes data to Adobe Analytics, Adobe Target, or Adobe Audience Manager — then an event dataset is not required. Each of those services has its own configuration requirements independent of AEP datasets.

Additional Notes on Event Datasets

  • You can also configure override event datasets on top of the primary one. These allow you to route specific events to different datasets without changing your implementation code.
  • Dynamic datastream configurations (rules-based routing) also let you route events to different datasets based on event payload conditions — but a default primary dataset must still be configured for the AEP service as a fallback.
  • Rule limits: you can have up to 5 rules per service (e.g., 5 for AEP, 5 for Analytics, etc.) on the same datastream.

In summary: An event dataset is only mandatory if you add the Adobe Experience Platform service to your datastream. It is not required for the datastream itself to be created or for other services to function.
