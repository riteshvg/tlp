What is Analysis Workspace in CJA?

Analysis Workspace in CJA

Analysis Workspace is a flexible, freeform analysis environment in Customer Journey Analytics that allows you to quickly build analyses and share insights based on your data. It's the core reporting and visualization tool in CJA.

Key Capabilities

Drag-and-Drop Interface

  • Combine data components, tables, and visualizations to craft your analysis
  • Dynamically build reports by dragging dimensions and metrics onto freeform tables

Quick Insight Generation

  • Rapidly explore data and uncover trends
  • Use statistical modeling for automatic anomaly detection
  • Apply various attribution models to understand which touchpoints drive conversions

Sharing & Collaboration

  • Share projects with anyone in your organization
  • Schedule reports for automated delivery
  • Add comments within projects to discuss findings in context

Cross-Channel Analysis

  • Analyze complete customer journeys across channels and devices
  • Combine online and offline data sources (websites, mobile apps, CRM, call centers, in-store systems)
  • Get a unified, person-centric view of your data

Main Interface Areas

| Area | Function |

|------|----------|

| Left Rail | Add panels, visualizations, and components; access the Data Dictionary |

| Canvas | Main workspace where you drag content to build your project |

| Report Suite/Data View Selector | Choose which data source (data view) to use for analysis |

Getting Started

To create your first Analysis Workspace project:

1. Select Workspace in the top menu

2. Go to Projects in the left navigation

3. Select Create project → Blank Workspace project

4. Select your data view (which links to your connection and data)

5. Start dragging dimensions and metrics onto the Freeform table to build your first report
