How do I delete AEP dataset batches that are 2 months old

Deleting AEP Dataset Batches by Age

Based on the retrieved documentation, there are a few important things to clarify about your use case:

Important Limitations to Know First

> Data Lifecycle does not support batch deletion. The Advanced Data Lifecycle Management API works at the dataset level (full dataset expiration) or record/row level (by primary identity) — not at the individual batch level by age.

Additionally, datasets created and used by Adobe applications (such as Adobe Analytics, Adobe Audience Manager, or Offer Decisioning) cannot be deleted.

Your Available Options

Option 1: Schedule Full Dataset Expiration (Dataset Level)

If you want to delete an entire dataset after a period of time, use the Data Hygiene API `/ttl` endpoint to schedule a dataset expiration:

  • A dataset expiration is a delayed delete operation
  • After the scheduled expiry time, there may be up to 24 hours of delay before deletion begins
  • Once initiated, it can take up to 7 days to remove all traces from Experience Platform systems
  • Deletion affects the data lake, Identity Service, and Real-Time Customer Profile separately
  • You can cancel or reschedule the expiry before deletion begins (once it reaches `executing` status, it cannot be modified)

> ⚠️ Before scheduling deletion, manually update any dataflows ingesting into that dataset to avoid breaking downstream workflows.

You can also manage dataset expirations through the Experience Platform UI under Data Lifecycle management.

Option 2: Delete Individual Records by Identity (Row Level)

If you want to remove specific records (e.g., records belonging to users from 2 months ago) rather than full batches, use the `/workorder` endpoint of the Data Hygiene API to delete rows by primary identity.

Option 3: Delete a Profile-Enabled Dataset via UI

If your dataset is Profile-enabled, deleting it through the UI will remove it from:

  • The data lake
  • Identity Service
  • The Profile store

Steps:

1. Navigate to Datasets in the Experience Platform UI and open the Browse tab

2. Locate the dataset you wish to delete

3. Select the ellipsis (...) next to the dataset name

4. Select Delete from the dropdown menu

5. Confirm deletion in the confirmation dialog

Recommendation

If your goal is to purge older data on a rolling basis, the closest supported approach is to:

  • Partition your data into separate datasets by time period (e.g., one dataset per month), then use dataset expiration via the `/ttl` endpoint or the Data Lifecycle UI to schedule deletion of the older dataset.

There is no native "delete batches older than X days" filter — batch-level age-based deletion is not supported by Data Lifecycle management.
