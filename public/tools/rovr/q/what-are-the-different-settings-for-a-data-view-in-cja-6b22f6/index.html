What are the different settings for a data view in CJA?

Based on the retrieved documentation, here are the key settings you can configure in a CJA data view:

Core Configuration Areas

1. Configure Step

  • Connection: Select which connection your data view will use
  • Name and Description: Identify and describe your data view
  • Settings: Configure various operational parameters
  • Container: Set container-level configurations
  • Calendar: Define calendar settings for your reporting

2. Components Step

Add schema fields and standard components to your data view:

  • Metrics: Numeric values you want to analyze
  • Dimensions: Categorical attributes for segmentation and breakdown

You can also create derived fields for fields that:

  • Don't have the proper data type
  • Aren't in the proper format
  • Need modification for your business logic

3. Settings Step

Includes various operational configurations for how your data view behaves in Analysis Workspace

Key Data View Capabilities

Data views allow you to:

  • Set attribution settings (e.g., First Touch vs. Last Touch) for dimensions
  • Configure visit timeout parameters
  • Define session settings
  • Set friendly names for dimensions and metrics
  • Configure time zone settings
  • Format and customize how metrics display

Important Limits

  • Up to 5,000 metrics can be added to a single data view
  • Up to 5,000 dimensions can be added to a single data view

For more detailed information on specific component settings and configuration options, refer to the Data views overview documentation in Adobe Experience League.
