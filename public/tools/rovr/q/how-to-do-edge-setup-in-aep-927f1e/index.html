Edge Setup in Adobe Experience Platform

Overview

The Edge Network setup in AEP involves configuring several components that work together to collect client-side customer experience data, send it to the Adobe Experience Platform Edge Network, where it can be enriched, transformed, and distributed to Adobe or non-Adobe destinations.

High-Level Architecture

```

Your Website/App

↓

Web SDK (Tags/Launch Extension)

↓

Adobe Experience Platform Edge Network

↓

Datastream (routes data to services)

↓

AEP / Adobe Target / AJO / Analytics / etc.

```

Prerequisites

Before starting the edge setup, ensure you have:

  • Access to Adobe Experience Platform Data Collection UI
  • Access to Adobe Experience Platform
  • Appropriate admin/developer permissions
  • A website or app where you can deploy the Web SDK

Step-by-Step Edge Setup

Step 1: Create an XDM Schema

1. Navigate to Adobe Experience Platform UI → Schemas

2. Click Create Schema

3. Select the appropriate base class (XDM ExperienceEvent for behavioral data or XDM Individual Profile for profile data)

4. Give your schema a name

5. Add the required field groups relevant to your use case (e.g., AEP Web SDK ExperienceEvent, IdentityMap, etc.)

6. Enable the schema for Profile if you want data to flow into Real-Time Customer Profile

7. Click Save

Step 2: Create a Dataset

1. Navigate to AEP UI → Datasets

2. Click Create Dataset from Schema

3. Select the schema you created in Step 1

4. Name your dataset

5. Enable the dataset for Profile if required

6. Click Finish

Step 3: Configure a Datastream

The Datastream tells the Edge Network where to route your incoming data.

1. Navigate to Data Collection UI → Datastreams

2. Click New Datastream

3. Give it a name and description

4. Select the XDM Schema you created in Step 1

5. Add services based on your use case:

| Service | Purpose |

|---|---|

| Adobe Experience Platform | Send data to AEP datasets and Real-Time Profile |

| Adobe Analytics | Forward data to Adobe Analytics |

| Adobe Target | Enable personalization via Target |

| Adobe Journey Optimizer | Enable AJO messaging and personalization |

6. For each service, configure the relevant dataset mappings

7. Click Save

Step 4: Install and Configure Web SDK

Option A: Via Tags (Recommended)

1. Navigate to Data Collection UI → Tags

2. Create a new Tag Property (or use an existing one):

  • Name your property
  • Select Web as the platform
  • Enter your domain

3. Inside the property, navigate to Extensions

4. Click Catalog and search for Adobe Experience Platform Web SDK

5. Click Install

6. In the Web SDK extension configuration:

  • Set the Datastream to the one created in Step 3
  • Configure the Identity namespace (typically ECID)
  • Set Edge domain if using a custom first-party domain

7. Click Save

Step 5: Create an XDM Object Data Element

1. Inside your Tag Property, navigate to Data Elements

2. Click Create New Data Element

3. Name it (e.g., `XDM Object`)

4. Select Extension: Adobe Experience Platform Web SDK

5. Select Data Element Type: XDM Object

6. Select your XDM Schema from the dropdown

7. Map your website variables to the corresponding XDM fields

8. Click Save

Step 6: Create a Rule to Send Data

1. Inside your Tag Property, navigate to Rules

2. Click Create New Rule

3. Name it (e.g., `Send Page View Event`)

4. Under Events, add:

  • Extension: Core
  • Event Type: Page Bottom (or DOM Ready / Library Loaded)

5. Under Actions, add:

  • Extension: Adobe Experience Platform Web SDK
  • Action Type: Send Event
  • Type: `web.webpagedetails.pageViews`
  • XDM Data: Select the XDM Object data element you created

6. Click Keep Changes → Save

Step 7: Build and Publish the Library

1. Navigate to Publishing Flow in your Tag Property

2. Click Add All Changed Resources to a new library

3. Name the library (e.g., `Edge Setup v1.0`)

4. Select Development environment

5. Click Save & Build to Development

6. After testing, promote through Staging → Production

Step 8: Deploy the Embed Code

1. Navigate to Environments inside your Tag Property

2. Click the install icon next to your environment

3. Copy the embed code snippet

4. Paste it into the `<head>` section of your website

5. Deploy to your web property

Step 9: Validate Your Edge Setup

Using Browser Developer Tools

1. Open your website in a browser

2. Open Developer Tools → Network tab

3. Filter by `interact` in the search box

4. Refresh the page

5. You should see network calls from your website to the Adobe Edge Network populating

Using Adobe Experience Platform Assurance

1. Open AEP Assurance

2. Create a new Assurance session

3. Connect your browser/app session

4. Navigate to the Edge Delivery view

5. Use Send PageView Event to test

6. Inspect incoming events to confirm:

  • Data is reaching the Edge Network
  • XDM payload is correctly structured
  • Data is being routed to the correct services via the Datastream

7. If failures occur, use the Assurance link to review failed events

Optional: Configure Edge Segmentation for Personalization

If you want to use real-time personalization via edge profiles:

1. In AEP UI → Audiences, create your audience

2. Enable Edge Segmentation on the audience so membership is evaluated in real-time at the edge

3. Create an Active-On-Edge merge policy under Profiles → Merge Policies

4. Connect to an Adobe Target or Custom Personalization destination

5. Activate your edge audiences to that destination

Component Summary

| Component | Role in Edge Setup |

|---|---|

| XDM Schema | Defines the data structure sent to the edge |

| Dataset | Stores the ingested data in AEP |

| Datastream | Routes edge data to downstream services |

| Web SDK (Tag Extension) | Collects and sends data from the browser to the edge |

| XDM Data Element | Maps website variables to XDM fields |

| Tag Rule | Triggers when data is sent to the edge |

| Tag Library | Packages all rules/data elements for deployment |

| Assurance | Validates and troubleshoots edge data flow |

| Edge Profiles | Lightweight profiles served at the edge for real-time use cases |

| Edge Segmentation | Evaluates audience membership in real-time at the edge |

Important Notes

> ⚠️ Even if you only want to use Event Forwarding, you must still install and configure the Web SDK first before configuring event forwarding.

> ⚠️ You can also install and configure the Web SDK using raw code instead of Tags if preferred — this is done via the `configure` command in the Web SDK JavaScript library.
