Can I use Customer Journey Analytics to replace Adobe Analytics, or do I need both?

Can CJA Replace Adobe Analytics?

Short Answer

Yes, Customer Journey Analytics can fully replace Adobe Analytics — but Adobe recommends a transition period where both run simultaneously before fully disabling Adobe Analytics.

Adobe's Official Recommendation

Adobe recommends the following approach:

> "Transition fully from Adobe Analytics to Customer Journey Analytics. During the transition period, you should plan to run Adobe Analytics alongside Customer Journey Analytics in order to perform side-by-side data comparisons. When you are comfortable with the data, you can disable Adobe Analytics."

The Three Options Available to You

✅ Option 1: Fully Move to Customer Journey Analytics (Recommended)

  • Transition completely from Adobe Analytics to CJA
  • Run both platforms simultaneously during the transition period for side-by-side data validation
  • Once comfortable with data accuracy, disable Adobe Analytics
  • Most cost-effective long-term approach

⚠️ Option 2: Keep Both Analytics Products (Not Recommended)

  • Maintain both Adobe Analytics and Customer Journey Analytics contracts simultaneously
  • Adobe explicitly flags this as not recommended
  • Can be more expensive for your organization over time
  • Adds complexity of maintaining two separate analytics environments

🔄 Option 3: Disable Analytics Source Connector

  • Use this option when you want data exclusively from the Web SDK
  • The Analytics Source Connector is initially used to provide:
  • Side-by-side data comparison
  • Historical data access
  • Access to some features not fully available in CJA
  • Once you no longer need Adobe Analytics for these purposes, you can disable the connector

Why Keep Adobe Analytics Running During Transition?

Even though CJA can replace Adobe Analytics, there are important reasons to run both temporarily:

1. Side-by-Side Data Comparison

  • Validate that CJA data matches Adobe Analytics data
  • Build confidence in your new implementation before fully switching
  • Identify any discrepancies in data collection or processing

2. Historical Data Access

  • Adobe Analytics holds years of historical data
  • The Analytics Source Connector can bring this historical data into CJA
  • Ensures reporting continuity without data gaps

3. Feature Access During Transition

  • Some features may not be fully available in CJA during the transition period
  • Keeping Adobe Analytics running ensures no reporting gaps

Recommended Transition Path

| Phase | Action |

|---|---|

| Phase 1 | Implement Web SDK for CJA data collection |

| Phase 2 | Run Adobe Analytics & CJA simultaneously |

| Phase 3 | Perform side-by-side data comparisons |

| Phase 4 | Validate data accuracy and build confidence |

| Phase 5 | Disable Adobe Analytics when ready |

| Phase 6 | Optionally disable Analytics Source Connector |

Cost Consideration

Keeping both products long-term is:

  • ❌ More expensive over time
  • ❌ More complex to maintain
  • ❌ Not recommended by Adobe

Fully transitioning to CJA is:

  • ✅ More cost-effective
  • ✅ Simpler to maintain
  • ✅ Adobe's recommended approach

Bottom Line

Most organizations will eventually disable Adobe Analytics after upgrading to Customer Journey Analytics, primarily due to the cost and complexity of maintaining two analytics environments. The key is to take a measured, phased approach — running both platforms in parallel until you have full confidence in your CJA implementation.
