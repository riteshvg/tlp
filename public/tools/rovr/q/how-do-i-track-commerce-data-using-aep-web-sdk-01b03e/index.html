Tracking Commerce Data Using AEP Web SDK

Based on the retrieved documentation, here is how to track commerce, product, and order information using the Adobe Experience Platform Web SDK.

Overview

Commerce tracking in Web SDK uses the XDM Commerce Schema field group, which consists of two main parts:

1. The `commerce` object — indicates which commerce actions are happening (e.g., purchase, add to cart, product view)

2. The `productListItems` array — contains the product details associated with those actions

> Tip: If you are familiar with Adobe Analytics:

> - The `commerce` object maps to commerce events (the `events` variable)

> - The `productListItems` array maps to the `products` variable

Prerequisites

  • AEP Web SDK (`alloy.js`) installed and configured on your site
  • A datastream configured and connected to your desired Adobe solutions
  • An XDM schema with the Commerce field group enabled

The Two Core Objects

1. The `commerce` Object

Use this object to indicate what commerce action is occurring. Common actions include:

| Action | XDM Field | Description |

|---|---|---|

| Product view | `commerce.productViews` | User viewed a product detail page |

| Add to cart | `commerce.productListAdds` | User added item to cart |

| Cart view | `commerce.productListViews` | User viewed the cart |

| Checkout | `commerce.checkouts` | User initiated checkout |

| Purchase | `commerce.purchases` | User completed a purchase |

| Order details | `commerce.order` | Contains price totals, currency, order ID |

2. The `productListItems` Array

Use this array to pass individual product details:

| Field | Description |

|---|---|

| `productListItems.SKU` | Product SKU / unique identifier |

| `productListItems.name` | Product name |

| `productListItems.quantity` | Quantity of product |

| `productListItems.priceTotal` | Total price for the line item |

Implementation Examples

Track a Product View

```javascript

alloy("sendEvent", {

xdm: {

eventType: "commerce.productViews",

commerce: {

productViews: {

value: 1

}

},

productListItems: [

{

SKU: "ABC123",

name: "Running Shoes",

quantity: 1,

priceTotal: 89.99

}

]

}

});

```

Track an Add to Cart

```javascript

alloy("sendEvent", {

xdm: {

eventType: "commerce.productListAdds",

commerce: {

productListAdds: {

value: 1

}

},

productListItems: [

{

SKU: "ABC123",

name: "Running Shoes",

quantity: 2,

priceTotal: 179.98

}

]

}

});

```

Track a Purchase / Order

```javascript

alloy("sendEvent", {

xdm: {

eventType: "commerce.purchases",

commerce: {

purchases: {

value: 1

},

order: {

purchaseID: "ORD-98765",

currencyCode: "USD",

priceTotal: 179.98

}

},

productListItems: [

{

SKU: "ABC123",

name: "Running Shoes",

quantity: 2,

priceTotal: 179.98

}

]

}

});

```

Key Notes

  • The `commerce` object fields (e.g., `purchases`, `productListAdds`) use a `value: 1` pattern to indicate the event fired — similar to how binary commerce events work in Adobe Analytics
  • The `commerce.order` object holds order-level details like `purchaseID`, `currencyCode`, and `priceTotal`
  • Multiple products can be passed in the `productListItems` array simultaneously
  • This data is sent to the Experience Platform Edge Network and routed to downstream solutions (Adobe Analytics, AEP datasets, etc.) based on your datastream configuration
