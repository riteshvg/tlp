What features or capabilities in Adobe Analytics are not yet available in Customer Journey Analytics?

Features Not Yet Fully Available in Customer Journey Analytics

Overview

While Customer Journey Analytics has full support for most Adobe Analytics features, there are a small number of features that are either not yet available or have differences in how they work in CJA.

Features NOT Yet Available in CJA

1. Activity Map

| Feature | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Activity Map overlay | ✅ Available | ❌ Not yet available |

| Link tracking visualization | ✅ Available | ❌ Not yet available |

2. Contribution Analysis

  • Adobe Analytics — Full Contribution Analysis available natively
  • Customer Journey Analytics — Not fully available yet
  • Adobe notes this as one of the key features requiring consideration during upgrade

3. Data Feeds

  • Adobe Analytics — Full Data Feeds export functionality available
  • Customer Journey Analytics — No exact replacement yet, but similar functionality can be achieved through:
  • 📊 Full Table Export — Export complete Workspace tables to cloud storage
  • 🗄️ Experience Platform Dataset Export — Export raw datasets from AEP
  • 🔧 Experience Platform Data Access API — Programmatic data access
  • 📈 BI Tool Integration — Connect BI tools directly to CJA data
  • 🔌 Reporting API — Pull data programmatically

Features With Differences in CJA

4. Calculated Metrics

| Aspect | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Availability | ✅ Full support | ✅ Full support |

| Migration | Native | Not automatically ported — must be recreated in CJA |

5. Marketing Channels

| Aspect | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Native feature | ✅ Marketing Channels rules | ❌ Not a native feature |

| CJA equivalent | N/A | Derived Fields within a Data View |

| Migration path | Native setup | Must create a marketing channel derived field |

6. Classification Data

| Aspect | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Native feature | ✅ Classification sets | ❌ Not directly available |

| CJA equivalent | N/A | Lookup Datasets in AEP |

| Migration path | Native setup | Must create a lookup dataset for each classified dimension |

7. eVars and Props

| Aspect | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Custom variables | eVars, props, events | Not applicable |

| CJA equivalent | N/A | XDM-based dimensions and metrics (unlimited) |

| Merchandising eVars | ✅ Available | ✅ Supported via binding dimensions and binding metrics |

8. Components & Projects Migration

| Aspect | Adobe Analytics | Customer Journey Analytics |

|---|---|---|

| Workspace projects | ✅ Native | Requires manual migration to CJA |

| Segments | ✅ Native | Must be recreated as Filters in CJA |

| Calculated metrics | ✅ Native | Must be recreated in CJA |

Features With FULL Support in CJA

For reference, here are key features that ARE fully supported:

| Feature | CJA Support |

|---|---|

| Anomaly Detection | ✅ Full support |

| Asset Transfer | ✅ Full support |

| Attribution Models | ✅ Full support |

| Bot Detection | ✅ Full support |

| Custom Calendars | ✅ Full support |

| Date Comparisons | ✅ Full support |

| Date Ranges | ✅ Full support |

| Dimensions (unlimited) | ✅ Full support |

| GDPR Deletion | ✅ Full support |

| Lift & Confidence Reporting | ✅ Full support via Experimentation Panel |

| List Variables / List Props | ✅ Full support via XDM string arrays |

| Metrics (unlimited) | ✅ Full support |

| CSV Download | ✅ Full support |

| Calendar Events / Annotations | ✅ Full support |

Summary: Key Gaps to Plan For

If you are upgrading from Adobe Analytics to CJA, here are the critical gaps to address in your planning:

| Gap | Recommended Action |

|---|---|

| Activity Map | Plan to retain Adobe Analytics access until available in CJA |

| Contribution Analysis | Plan to retain Adobe Analytics access until available in CJA |

| Data Feeds | Evaluate Full Table Export, AEP Dataset Export, or BI Tool integration as alternatives |

| Marketing Channels | Recreate using Derived Fields in CJA Data Views |

| Classifications | Recreate using Lookup Datasets in AEP |

| Calculated Metrics | Manually recreate in CJA |

| Segments | Recreate as Filters in CJA |

| Workspace Projects | Migrate projects and components to CJA |

Important Note

Adobe explicitly states:

> "A small set of features are not yet fully available in Customer Journey Analytics. If you need access to these features, it might be necessary to use Adobe Analytics in conjunction with Customer Journey Analytics until these features are available."
