What types of bots does Adobe Experience Platform's bot detection identify and filter?

Types of Bots Identified by AEP Bot Detection

Based on the retrieved documentation, here is what is covered regarding the types of bots that AEP's bot detection identifies and filters:

Sources of Bot Identification

AEP's bot detection draws from two sources to identify non-human traffic:

1. IAB/ABC International Spiders and Bots List

This is an industry-standard, third-party list that identifies known automated traffic, including:

  • Search engine crawlers (e.g., Googlebot, Bingbot)
  • Web scrapers
  • Spiders
  • Scripted scanners
  • Monitoring tools

2. Custom Bot Detection Rules

You can define your own rules to identify bots based on:

  • Specific IP addresses
  • IP address ranges
  • Request headers

Entry Points Covered

Bot detection applies to traffic arriving via any of these collection methods:

  • Web SDK
  • Mobile SDK
  • Edge Network API

How Detected Bots Are Flagged

When a request matches a bot detection rule, the XDM schema is updated with a bot score:

```json

{

"botDetection": {

"score": 1

}

}

```

The `score` field in the Bot Detection XDM field group ranges from 0 to 1:

  • 0 = traffic is not a bot
  • 1 = traffic is identified as a bot

This score is then available for downstream routing logic (e.g., via Dynamic Datastream Configurations) to disable or quarantine the traffic for services like Adobe Analytics and Adobe Target.

What the Documentation Does Not Specify

The retrieved documentation does not provide an exhaustive list of every specific bot or crawler included in the IAB/ABC list. That list is maintained externally by the IAB/ABC organization and is updated independently of Adobe's documentation.
