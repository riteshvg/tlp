Creating a Connection in Customer Journey Analytics from Adobe Experience Platform

A connection integrates AEP datasets into CJA Workspace, enabling you to report and analyze your Experience Platform data.

Prerequisites

Before creating a connection, ensure you have:

  • A configured schema in AEP
  • At least one dataset created in AEP
  • Access to the Customer Journey Analytics UI

Step-by-Step Instructions

Step 1: Navigate to Connections

1. In the Customer Journey Analytics UI, select [!UICONTROL Connections] (optionally under [!UICONTROL Data management]) from the top menu.

2. Select [!UICONTROL Create new connection].

Step 2: Configure Connection Settings

In the [!UICONTROL Untitled connection] screen:

  • Enter a Connection name and Connection description in the [!UICONTROL Connection Settings] section.
  • Under [!UICONTROL Data settings]:
  • Select the correct [!UICONTROL Sandbox] from the sandbox list.
  • Select the appropriate [!UICONTROL Average number of daily events] (e.g., less than 1 million).

Step 3: Add Datasets

1. Select [!UICONTROL Add datasets].

2. In the [!UICONTROL Select datasets] step, select the AEP dataset(s) you want to include in this connection.

3. Select [!UICONTROL Next].

Step 4: Configure Dataset Settings

For each dataset added:

  • [!UICONTROL Person ID] — Select a Person ID from the available identities defined in the dataset's schema in AEP. This is used for identity stitching.
  • [!UICONTROL Data source type] — Select the appropriate source type from the list. If selecting [!UICONTROL Other], add a description for the data source.
  • [!UICONTROL Import all new data] — Toggle on/off based on whether you want ongoing new data to flow into CJA.
  • [!UICONTROL Dataset backfill existing data] — Toggle on/off based on whether you want to backfill historical data.

Once configured for all datasets, select [!UICONTROL Add datasets].

Step 5: Save the Connection

Select [!UICONTROL Save] to finalize and create the connection.

> Note: After creating your connection, it may take a few hours before your data becomes available in CJA for reporting and analysis.

What's Next?

Once the connection is saved, you can proceed to:

  • Create a Data View — to define how the connected dataset fields appear in CJA Workspace.
  • Build Workspace Projects — to start analyzing your AEP data.
