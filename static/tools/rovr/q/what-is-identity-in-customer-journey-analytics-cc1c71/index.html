Identity in Customer Journey Analytics

Identity is one of the most critical components of Customer Journey Analytics. It's the foundation that allows you to connect and stitch multiple data sources together to create a unified view of your customer.

Why Identity Matters

In Customer Journey Analytics, an identifier that exists across all your channels and the corresponding data allows you to:

  • Stitch multiple data sources together
  • Track customer journeys across channels and devices
  • Create cross-channel visualizations
  • Analyze complete customer interactions in a unified way

How Identity Works in CJA

When you set up a connection, you define a Person ID for each dataset. This Person ID is the identifier used to:

  • Partition data in Experience Platform
  • Serve as the primary key for analysis in Customer Journey Analytics
  • Enable cross-channel analysis and stitching

Configuring Identity Options

When setting up your connection, you have two primary options for selecting your Person ID:

Use Primary Identity Namespace

  • Instructs Customer Journey Analytics to find the identity in the Identity Map marked with a `primary=true` attribute
  • Uses that identity as the Person ID for each row
  • This is the identity also used by Experience Platform for partitioning

Select a Specific Namespace

  • If you don't use the primary identity, you can select a specific identity namespace
  • Customer Journey Analytics will search each row's Identity Map for this namespace key
  • You must know which namespaces are present in your data; they are not auto-detected
  • All possible namespaces appear in the dropdown menu

Important Identity Considerations

For your identities to work effectively across all channels, consider the following:

  • ID exists across sources: The ID must exist or be added to all data sources you want to bring into CJA
  • Populated on each row: The ID should be populated on each row of data
  • No PII: Don't include personally identifiable information; apply hashing to anything sensitive
  • Consistent format: Use the same format across all sources (same length, same hashing method)

Cross-Channel Analysis

For datasets like Adobe Analytics where an identity may not exist on every row, you can use Cross-channel Analysis (Stitching) to bridge the gap—for example, when a customer is identified only by their ECID and when an identity is collected after authentication.
