What is a Connection in CJA?

A connection in Customer Journey Analytics is the foundation that allows you to combine multiple Adobe Experience Platform datasets into a single data source for analysis. It's the first critical step in setting up CJA.

Purpose

Connections define:

  • Which datasets from Experience Platform are ingested into CJA
  • How datasets relate to each other (through shared identity fields)
  • Data availability — the fields you can later use as dimensions and metrics in data views and Analysis Workspace projects

Key Points

Multiple Datasets in One Connection

  • You can combine multiple Experience Platform datasets (event, lookup, profile, and summary datasets) into a single connection
  • Datasets are linked together based on shared identity fields like customer IDs

Foundation for Data Views

  • Connections determine what data is available
  • Data views are built on top of connections to define specific dimensions and metrics for analysis
  • You cannot create a data view without first establishing a connection

Admin-Level Setup

  • Connections are configured by Customer Journey Analytics product administrators
  • Once created, the connected data is readily available for ongoing analysis and exploration

Connections Workflow

The typical workflow is:

1. Create a Connection → Select and combine datasets from Experience Platform

2. Set up a Data View → Define dimensions and metrics based on the connection

3. Build Reports → Analyze the data in Analysis Workspace

Example: Creating a Connection

When you create a connection, you:

1. Select Connections from the Data Management menu

2. Choose Create new connection

3. Specify the connection name, sandbox, and daily event volume

4. Add datasets (e.g., event data, customer profiles, lookup tables)

5. Configure each dataset's settings (Person ID, timestamp, dataset type)

6. Save the connection

Once saved, that connection becomes available for creating data views and analyzing your cross-channel customer journey data.

Why Connections Matter

Connections enable CJA's core strength: unifying online and offline data sources across channels, devices, and systems to analyze the complete customer journey in a single person-centric view.
