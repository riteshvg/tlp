Configuring Profile Attributes for Replication to the Edge Network

The primary mechanism documented for controlling which profile attributes get projected to the Edge Network is through the Custom Personalization With Attributes destination connection in AEP.

Steps to Configure Attribute Replication to Edge

Prerequisites

  • A configured Datastream with Adobe Experience Platform enabled as a service
  • A Web SDK, Mobile SDK, or Edge Network API implementation
  • Required permissions: [!UICONTROL View Destinations], [!UICONTROL Activate Destinations], [!UICONTROL View Profiles], and [!UICONTROL View Segments]

> Important: For attribute-based personalization (not just audience membership), you must use the Edge Network API with an authenticated server-side integration. Web SDK and Mobile SDK alone only support personalization based on audience membership.

Step 1: Create a Custom Personalization With Attributes Destination

1. In the AEP UI, navigate to [!UICONTROL Destinations] and create a new connection

2. Select [!UICONTROL Custom Personalization With Attributes]

3. In the [!UICONTROL Datastream ID] field, select the datastream you want to use

4. Set an [!UICONTROL Integration alias] to help identify this connection later

Step 2: Activate Audiences and Map Attributes

Once the destination connection is created:

1. Navigate to the destination and begin the audience activation workflow

2. Select the audiences you want to activate to the edge

3. Proceed to the [!UICONTROL Mapping] step

4. In the [!UICONTROL Source field] column, select [!UICONTROL Add new field] and search or navigate to the XDM attribute field you want projected to the edge

5. Map the source attribute to a [!UICONTROL Target attribute]

6. Repeat for each attribute you want available on the edge

> Note: Adding attributes in the mapping step is optional — if you skip it, personalization will still occur based on audience membership and identity map qualifications only. Attributes are only replicated to the edge when explicitly mapped here.

Important Behavioral Note

When you map an attribute to this destination:

  • If the value of that attribute changes on a profile, that profile will be re-evaluated and re-activated to the personalization destination
  • If a new attribute is added to a profile that matches the mapping, that profile will also become active and be pushed to the edge
