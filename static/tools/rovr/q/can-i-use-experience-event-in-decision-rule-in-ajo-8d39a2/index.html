Using Experience Events in Decision Rules in AJO

Based on the retrieved documentation, event-based offers are currently not supported in Adobe Journey Optimizer's Decision Management (Offer Management).

> ⚠️ Important Limitation:

> If you create a decision rule based on an event, you will not be able to leverage it in an offer within Journey Optimizer's legacy Decision Management capability.

What You Can Use Instead

While direct experience event-based decision rules are not supported in offers, you have alternative approaches:

1. Audiences (Segments)

  • Build an Adobe Experience Platform audience that incorporates experience event logic (e.g., "customers who viewed product X in the last 7 days") using the Segment Builder
  • Apply that audience as an eligibility constraint on your offer
  • Note: The audience is computed periodically and may not always reflect the absolute latest state at decision time

2. Computed Attributes

  • Use computed attributes — profile-level attributes derived from aggregating experience event data over time (e.g., "total purchases in last 30 days")
  • These are stored at the profile level and can be referenced in decision rules since they are profile attributes, not raw events

3. Decision Rules with Dataset Lookup (Experience Decisioning)

  • In the newer Experience Decisioning capability (available via code-based experience and email channels), you can use Adobe Experience Platform dataset attributes in decision rules
  • This allows dynamic, external data to drive eligibility criteria

Key Distinction: Audiences vs. Decision Rules

| | Audiences | Decision Rules |

|---|---|---|

| Based on | Profile attributes + experience events | Profile attributes (no raw events) |

| Evaluated | Periodically (batch) | Every time a decision is made (real-time) |

| Use in offers | ✅ Supported | ⚠️ Events not supported |

Recommendation

If your use case requires experience event logic (e.g., "user clicked X today"), consider:

1. Building an AEP audience with that event logic and using it as the offer eligibility constraint

2. Using computed attributes that summarize the event behavior into a profile attribute

3. Exploring Experience Decisioning (the newer capability) for more advanced rule configurations
