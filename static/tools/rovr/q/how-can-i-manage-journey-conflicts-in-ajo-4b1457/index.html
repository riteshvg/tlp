Managing Journey Conflicts in Adobe Journey Optimizer

Adobe Journey Optimizer provides a comprehensive set of tools to help you identify, manage, and resolve conflicts across journeys and campaigns — preventing customer fatigue and ensuring the right messages reach your audience at the right time.

Conflict Management Tools Overview

AJO offers four main tools for conflict management and prioritization:

1. Conflict Detection – Identify overlapping journeys and campaigns

2. Priority Scores – Control which journey takes precedence

3. Rule Sets – Limit frequency and entry across journeys

4. Journey Arbitration – Suppress lower-priority journey entries

1. View Potential Conflicts

When authoring a journey or campaign, you can proactively check for overlaps with other active or scheduled journeys.

Steps:

1. Open your journey or campaign properties while authoring.

2. Assign at least one of the following settings: Start / End Date, Audience, Channel, Channel Configuration, or Rule Set.

3. Click Save to save those settings.

4. Click the View Potential Conflicts button in the journey or campaign properties.

5. The Potential Conflicts window opens, showing all overlapping journeys/campaigns.

> Note: The View Potential Conflicts button is only available for live and scheduled journeys/campaigns. It becomes selectable only after the required settings are saved.

Conflicts are checked across:

  • Overlapping audience targeting
  • Concurrent timelines (start/end dates)
  • Shared communication channels
  • Shared channel configurations
  • Shared rule sets

2. Priority Scores

When multiple journeys or campaigns target the same profile through the same channel, priority scores determine which one is delivered.

  • Assign a score from 0 to 100 to each journey or campaign (higher = more important).
  • For inbound channels (e.g., In-App, Web), the action with the highest priority score is shown.
  • If two journeys/campaigns share the same priority score, the most recently modified one takes precedence.

Where to configure: In the journey properties under the Conflict Management section, set the Priority Score field.

3. Rule Sets (Frequency Capping & Journey Entry Limits)

Rule sets allow you to define capping rules that restrict how many times a profile can enter journeys or receive messages.

You can configure:

  • Journey frequency capping – Limit the number of journeys a profile can enter per day, week, or month, or the number of concurrent journeys running simultaneously.
  • Channel frequency capping – Set channel-specific limits (e.g., no more than 3 emails per week).
  • Communication type rules – Apply granular rules by type (e.g., Sales vs. Promotional) to avoid overloading customers with similar messages.
  • Quiet Hours – Define time windows during which no messages are sent (supports Email, SMS, Push, WhatsApp).

Where to configure: In the journey properties under Conflict Management, apply a Rule Set to the journey.

4. Journey Arbitration

Journey Arbitration allows you to suppress entry into lower-priority journeys when a customer qualifies for a higher-priority one simultaneously. This ensures customers are not pulled into multiple conflicting journeys at once.

Conflict Management Section in Journey Properties

All conflict tools are accessible directly from the Conflict Management section of the journey properties panel:

From here you can:

  • Apply a Rule Set for capping
  • Set a Priority Score
  • Click View Conflicts to check for overlaps

Using AI Assistant for Conflict Analysis

The Journey Analyze Agent in AI Assistant can also help you detect conflicts through natural language prompts, such as:

  • "Are there any scheduling conflicts for journey [Journey Name]?"
  • "Show me audience overlap conflicts for journey [Journey Name]"
  • "Which audiences are used in more than 5 journeys?"

This requires View Journeys and View Segments permissions.
