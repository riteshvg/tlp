Learning Adobe Launch (Adobe Data Collection / Tags) from Scratch

Adobe Launch is now officially called Adobe Tags (part of Adobe Data Collection in Adobe Experience Platform). Here is a structured learning path from scratch:

What is Adobe Launch/Tags?

Adobe Launch is a tag management system (TMS) that allows you to deploy and manage marketing and analytics tags on your website or mobile app — without hard-coding every tool directly into your site. It acts as a central hub for:

  • Deploying Adobe Analytics
  • Deploying Adobe Target
  • Deploying Adobe Experience Platform Web SDK
  • Deploying third-party tags (Google, Meta, etc.)

Core Concepts to Understand First

Before touching the UI, make sure you understand these building blocks:

| Concept | Description |

|---|---|

| Properties | A container for all your tags for a specific website or app |

| Extensions | Pre-built connectors (e.g., Adobe Analytics extension, Core extension) |

| Data Elements | Variables that capture data from your website (e.g., page name, product ID) |

| Rules | Logic that defines WHEN to fire a tag and WHAT to do (Event → Condition → Action) |

| Environments | Development, Staging, and Production — where your library is published |

| Libraries | A bundle of rules, data elements, and extensions that gets published to an environment |

Step-by-Step Learning Path

Step 1: Access Adobe Data Collection

1. Log in to experience.adobe.com

2. Click on Data Collection from the app switcher

3. You will land on the Tags interface (formerly Launch)

4. Make sure you have the correct permissions — ask your admin to grant you access to at least one Property

Step 2: Create Your First Property

1. In Data Collection, click Tags in the left navigation

2. Click New Property

3. Enter a Name for your property (e.g., "My Website - Dev")

4. Select Web as the platform

5. Enter your domain (e.g., `example.com`)

6. Click Save

> A Property is your working container — think of it as your project folder.

Step 3: Explore Extensions

1. Open your newly created property

2. Click Extensions in the left navigation

3. You will see the Core extension already installed by default

4. Click Catalog to browse available extensions

5. Install the Adobe Analytics extension:

  • Click Install next to Adobe Analytics
  • Enter your Report Suite ID
  • Configure general settings
  • Click Save

Step 4: Create Data Elements

Data Elements are the variables that pull data from your website.

1. Click Data Elements in the left navigation

2. Click Create New Data Element

3. Give it a name (e.g., `Page Name`)

4. Select Extension: Core

5. Select Data Element Type: Page Info → Page Name

6. Click Save

> Common data elements to create: Page Name, Page URL, User ID, Product Name, Form Name

Step 5: Create Rules

Rules define the logic for when and how your tags fire. Every rule has three parts:

  • Events — what triggers the rule (e.g., page load, button click)
  • Conditions — optional filters (e.g., only on homepage)
  • Actions — what happens (e.g., send an Adobe Analytics beacon)

To create your first rule:

1. Click Rules in the left navigation

2. Click Create New Rule

3. Name your rule (e.g., `Page View - All Pages`)

4. Under Events, click Add:

  • Extension: Core
  • Event Type: Page Bottom (or Window Loaded)
  • Click Keep Changes

5. Under Actions, click Add:

  • Extension: Adobe Analytics
  • Action Type: Send Beacon
  • Select s.t() (page view)
  • Click Keep Changes

6. Click Save

Step 6: Build and Publish a Library

After creating rules and data elements, you need to bundle and publish them:

1. Click Publishing Flow in the left navigation

2. Click Add Library

3. Name the library (e.g., `v1.0 Initial Build`)

4. Select Development environment

5. Click Add All Changed Resources

6. Click Save and Build to Development

7. Once built, click Submit for Approval → Approve → Build and Publish to Production

Step 7: Install the Launch Embed Code on Your Website

1. Go to Environments in the left navigation

2. Click the box icon next to the Development environment

3. Copy the `<script>` tag provided

4. Paste it in the `<head>` section of your website HTML

5. Repeat for Staging and Production environments with their respective embed codes

Step 8: Validate Your Implementation

Use these tools to verify tags are firing correctly:

| Tool | Purpose |

|---|---|

| Adobe Experience Platform Debugger (Chrome Extension) | Inspect what Adobe tags are firing on a page |

| Browser Developer Tools (Console/Network tab) | Check network requests going to Adobe servers |

| Launch's built-in Debug mode | Step through rule execution in the browser |

To use AEP Debugger:

1. Install the Adobe Experience Platform Debugger Chrome extension

2. Open your website

3. Click the Debugger extension icon

4. Navigate to the Analytics or Launch tab to see what is firing

Recommended Learning Order (Summary)

| # | Topic | Focus |

|---|---|---|

| 1 | Properties | Create and configure your container |

| 2 | Extensions | Install Adobe Analytics, Core, and others |

| 3 | Data Elements | Capture page/user/product data |

| 4 | Rules | Define trigger logic (events, conditions, actions) |

| 5 | Publishing Flow | Dev → Staging → Production |

| 6 | Embed Code | Deploy on your website |

| 7 | Debugging | Validate with AEP Debugger |

| 8 | Web SDK (Advanced) | Learn the modern implementation method |

Next Step After Launch Basics

Once you are comfortable with Adobe Tags, the next evolution is learning the Adobe Experience Platform Web SDK (alloy.js), which is the modern, recommended way to send data to Adobe Analytics, Adobe Target, and AEP — all through a single tag and a Datastream.
