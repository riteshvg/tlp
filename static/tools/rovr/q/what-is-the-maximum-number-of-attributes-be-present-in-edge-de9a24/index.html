What is the maximum number of attributes be present in Edge for a profile

Based on the retrieved documentation, I don't have a specific guardrail stated for the maximum number of attributes that can be present on an Edge profile overall.

However, I can share what the documentation does specify about attribute limits in related contexts:

Attribute Limits by Use Case

For edge personalization destinations (Adobe Target and Custom Personalization):

  • Maximum of 30 attributes per sandbox when activating audiences to edge destinations for same-page and next-page personalization use cases.

For profile customization in the UI:

  • Maximum of 20 attributes that can be added to a single card in the profile details interface.

For Identity Graph:

  • Maximum of 50 identities per individual profile (though this is about identities, not attributes specifically).

Edge Profile Data Storage

The documentation does indicate that Edge Profile stores profile attributes, profile IDs, and qualified audience IDs, with a default data expiration of 14 days rolling from each access.

If you need information about the total attribute capacity for edge profiles beyond these edge personalization use cases, I'd recommend checking with your Adobe representative or consulting additional documentation specific to your implementation scenario.
