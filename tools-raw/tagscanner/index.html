Everything you need to keep a Tags property healthy

Core features are fully available, free, with no sign-in required.

🔍

Audit

Browse every rule with its events, conditions, actions, and custom code. Sortable, searchable, paginated — no more opening rules one by one in the Launch UI.

🕸️

Analyse

Full data element usage tracking: which rules reference each DE, which extensions use them, and DE-to-DE dependency chains. Deep Scan detects ghost dependencies referenced in custom code that don't exist in the compiled library.

🗺️

Visualise

Flow Diagram generates an interactive visual map of your entire property — data elements, rules, extensions, and the connections between them. Always reflects the current published library.

💻

Search

Global Code Search runs full-text search across every rule, data element, and extension — including all custom code blocks — with line-level match highlighting.

📤

Export

One-click .xlsx export of every rule, data element, and extension, including custom code — the export Launch itself can't give you.

🛠️

Debug

Environment Override redirects the live Tags library to dev or staging at the network level. No proxy tools, no test pages, no page changes required.

AI-powered features Preview / Beta

A manual audit that takes hours — TagScanner does it in under a minute.

🩺

AI Property Health Scan

An A–F health score for your entire property, with an executive summary, category scores, critical issues, and ranked recommendations.

💡

Custom Code Explanation

A plain-English breakdown of any custom code block: what it does, what data it reads, what it returns, risks, and ready-to-run debug commands.

💬

Ask AI

Natural language questions about your live property — "Which rules fire on page load?", "What data elements use the data layer?" — answered instantly, with conversation persistence.

AI features are available on a best-effort basis and require Google OAuth. Core features above are fully available with no restrictions and no sign-in.
